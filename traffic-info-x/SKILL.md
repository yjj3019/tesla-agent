# Traffic Info X

테슬라 차량에서 교통 정보를 경로 또는 주변 기준으로 요약합니다.

## 발동 조건 (강제 · 테슬라 최적화)
테슬라 차량 음성 호출용 문장. 아래 문장이 포함되면 이 스킬만 사용한다.

| 호출 문장 | 동작 | 비고 |
|-----------|------|------|
| **경로 교통정보 요약** | 경로 모드 | 기본 호출 (권장) |
| **교통정보 요약** | 경로 있으면 경로, 없으면 주변 | |
| **주변 교통정보** | 주변 모드 | 목적지 없을 때 |

- “해줘”, “알려줘” 등은 있어도 되고 없어도 된다.
- 위 핵심 문장이 없으면 이 스킬을 사용하지 않는다.
- 일치 시 직접 답변 금지.

## 모드
- **경로 모드** (우선): 네비게이션에 목적지가 설정되어 있으면 도로명·IC·웨이포인트 기준으로 요약
- **주변 모드** (폴백): 목적지가 없거나 경로를 확인할 수 없으면 **즉시** 현재 위치 반경 10~15km로 전환
- 두 모드 모두 최근 60분 이내 정보만 사용
- 날씨는 **반드시** 표시한다. 정보가 없다고 생략하지 않는다.
- **날씨 우선순위**
  1. **테슬라 Grok이 날씨 도구로 직접 확인**한 목적지(또는 현재 위치) 날씨를 항상 조회해 최상단에 표시
  2. 수집된 데이터(X, 사이트)의 날씨는 보조로만 참고
  3. 조회 자체가 실패했을 때만 “날씨 확인 불가”라고 명시 (생략 금지)
