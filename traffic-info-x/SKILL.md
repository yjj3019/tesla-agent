# Traffic Info X

테슬라 차량에서만 사용. 교통 요약.

## 호출 (이 문장만)
- **경로 교통정보 요약** → 경로 모드
- **교통정보 요약** → 경로 있으면 경로, 없으면 주변
- **주변 교통정보** → 주변 모드
- 그 외 문장에는 반응하지 않는다.
- 일치하면 직접 답변 금지. 이 스킬만 사용.

## 반드시 지킬 것 (어기면 실패)
1. **날씨 맨 위**. 테슬라 Grok이 확인한 **현재 기온**. 범위 금지. 생략 금지. 실패 시 “날씨 확인 불가”.
2. **네비 색상 읽기**. 지도에 노란 선이나 빨간 선이 보이면 그 구간 도로명을 말하고 “서행” 또는 “정체”라고 한다.
3. **금지 문장**: “전 구간 원활”, “수도권 전 구간”, “이상 징후 없음”, “문제없습니다”, “우회 필요 없음”.
4. **경로만**. 경로에 없는 도로·지역 정보는 말하지 않는다.
5. X 정보는 **최근 60분**만.

## 출력 (이 순서, 항목 빼지 말 것)
```
날씨: [상태] [기온]도
경로:
- [도로명]: 원활 / 서행 / 정체
원인: [있으면 한 줄, 없으면 생략]
소요: XX~YY분
```

## 모드
- 경로 있음 → 그 경로의 도로·IC만
- 경로 없음 → 현재 위치 반경 10~15km
