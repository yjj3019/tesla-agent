# Traffic Info X

테슬라 차량용 실시간 교통 정보 요약 스킬.

## 호출 문장

| 문장 | 동작 |
|------|------|
| **경로 교통정보 요약** | 경로 모드 (권장) |
| 교통정보 요약 | 경로 있으면 경로, 없으면 주변 |
| 주변 교통정보 | 주변 모드 |

## 핵심 규칙

1. **날씨 필수**: 테슬라 Grok이 확인한 현재 기온을 최상단에 표시. 생략 금지.
2. **네비게이션 색상 우선**: 지도의 초록/노란/빨간 구간을 도로명과 함께 보고.
3. **금지 표현**: “전 구간 원활”, “이상 징후 없음”, “문제없습니다”.
4. **경로 필터**: 현재 경로에 해당하는 정보만. 경로 밖은 제외.
5. **최근 60분**: X·사이트 정보는 1시간 이내만 사용.

## 출력 순서

```
**날씨**: [상태], [기온]도
**경로 교통량**
- [도로]: 🟢/🟡/🔴
**추가 원인** (경로 해당 시)
**예상 소요**: XX~YY분
```
