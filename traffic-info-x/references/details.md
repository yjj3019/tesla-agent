## 데이터 융합 알고리즘

### 입력
- nav: 테슬라 네비게이션 등급
- x: TrafficXAgent 결과
- site: SiteAgent 결과
- weather: WeatherAgent 결과

## 신뢰도
| 소스 | 기본 |
|------|------|
| 테슬라 네비게이션 | 0.8 |
| 테슬라 Grok 날씨 | 0.85 |
| 공개 사이트 | 0.75 |
| X (≤30분) | 0.6 |

## 심각도
| 등급 | 추가 지연 |
|------|-----------|
| 경미 | +3~8분 |
| 중간 | +8~15분 |
| 심각 | +15~30분 |

## 차선 영향
- 갓길: 경미
- 1차로: 중간
- 2차로 이상: 심각, 우회 권장

## 신뢰도 등급
- ≥0.75 높음
- 0.5~0.74 중간
- <0.5 낮음
