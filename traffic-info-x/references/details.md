## 데이터 융합 알고리즘

### 입력
- nav: 테슬라 네비게이션 등급 (있을 때)
- x: TrafficXAgent 결과
- site: SiteAgent 결과
- weather: WeatherAgent 결과 (테슬라 Grok 자체 확인 우선)

### 융합 단계
```
1. 유효 소스 필터
   sources = [s for s in (nav, x, site) if s.status == success and age <= 60min]

2. 등급 정규화
   grade ∈ {원활, 서행, 정체}
   severity = {원활:1, 서행:2, 정체:3}

3. 일치 판단
   if all grades equal:
     final = that grade
     confidence += 0.15
   else:
     apply Consensus with Fallback
     confidence -= 0.1

4. 원인 결합
   cause = highest priority among (사고 > 공사 > 행사 > 기상 > 교통량)

5. 날씨
   weather = 테슬라 Grok 자체 확인 우선
   수집 데이터 날씨는 보조로만 사용
```

## 신뢰도

| 소스 | 기본 |
|------|------|
| 테슬라 네비게이션 | 0.8 |
| 테슬라 Grok 날씨 | 0.85 |
| 공개 사이트 | 0.75 |
| X (≤30분) | 0.6 |
| X (30~60분) | 0.4 |

- 복수 일치: +0.15
- 충돌: -0.1
- 소스 실패: 해당 소스 감점

## 심각도 (사고)

| 등급 | 조건 | 추가 지연 |
|------|------|-----------|
| 경미 | 갓길/단순 접촉 | +3~8분 |
| 중간 | 1차로 점유 | +8~15분 |
| 심각 | 2차로 이상/다중 | +15~30분 |

## 오류 처리

| 상황 | 처리 |
|------|------|
| 날씨 실패 | “날씨 확인 불가” 후 계속 |
| X 실패 | 사이트/네비게이션으로 대체 |
| 사이트 실패 | X/네비게이션으로 대체 |
| 전부 실패 | “관련 구간 최근 정보 없음” |
| 타임아웃 | 해당 에이전트만 실패 처리 (기본 15초) |
| 재시도 | 실패 에이전트 1회 |

## 차선 영향 · 우회

### 차선 영향
| 점유 | 영향 | 권장 |
|------|------|------|
| 갓길만 | 경미 | 진행 |
| 1차로 | 중간 | 주의, 가능하면 우회 검토 |
| 2차로 이상 | 심각 | 우회 권장 |

### 우회 판단
- 심각 사고 또는 정체 + 대안 경로가 있을 때 우회 제안
- 대안이 없거나 우회 시 더 길어지면 “대기 권장”
- 우회 시 예상 추가 시간을 함께 표기

## 신뢰도 등급 매핑

| 점수 | 등급 |
|------|------|
| ≥ 0.75 | 높음 |
| 0.5 ~ 0.74 | 중간 |
| < 0.5 | 낮음 |

출력 시 “신뢰도: 중간” 형태로 표시한다.

## 예측 (단순 규칙)

- 기본: 네비게이션 예상 소요
- 사고/공사 시 심각도 지연 가산
  - 경미 +3~8분, 중간 +8~15분, 심각 +15~30분
- 최종 출력: “XX~YY분”
- 별도 AI 모델 없음 (규칙 기반)
