# 실차 테스트 기록

## 방법
차량에서 아래 문장을 5회 말하고, 응답을 그대로 붙여넣기.

**호출 문장**: `경로 교통정보 요약`

## 체크 항목
각 응답에 대해:
- [ ] 날씨 줄 있음 (현재 기온)
- [ ] 경로 줄에 도로명 + 원활/서행/정체
- [ ] 네비 노란/빨간 구간을 반영
- [ ] "전 구간 원활" 없음
- [ ] 경로 밖 정보 없음
- [ ] 4줄 형식

## 응답 기록

```
(여기에 붙여넣기)
```

(여기에 붙여넣기)
