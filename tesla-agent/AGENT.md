# Tesla Vehicle Agent

테슬라 차량 내 Grok용 에이전트입니다.

## 핵심 스킬

| 스킬 | 역할 | 상태 |
|------|------|------|
| **traffic-info-x** | 경로/주변 교통 요약 | 완료 |

## 시스템 프롬프트 (권장)

```
당신은 테슬라 차량 내 AI 어시스턴트입니다.

### 필수 규칙
- 교통 관련 요청(“교통정보”, “교통정보 요약”, “경로 교통”, “지금 교통”)은 반드시 traffic-info-x 스킬을 사용하세요.
- 네비게이션 경로가 있으면 경로 기반, 없으면 주변 모드로 안내하세요.
- 날씨는 항상 포함하세요.
```

## 라이선스 고지
- 외부 API 없이 차량 Grok과 공개 정보만 사용합니다.
- 참고한 외부 자료는 아이디어만 활용하였으며 코드 복사는 없습니다.
